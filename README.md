# Gestor Contable - Riasthems

**Gestor Contable** es una plataforma web moderna para la gestión eficiente de gastos y finanzas personales. Permite a los usuarios llevar el control de sus movimientos, analizar reportes avanzados y mantener la seguridad de sus datos en todo momento.

## Descripción

Esta plataforma está diseñada para facilitar la administración financiera de manera intuitiva y visual. Incluye:
- Panel de control con gráficos y reportes
- Registro y categorización de gastos
- Seguridad y privacidad de la información
- Acceso rápido y responsive desde cualquier dispositivo

## Tecnologías y Estilo Visual

- **Framework:**           React + Vite
- **Backend:(servidor)**   Express 
- **ORM**                  Prisma 
- **Base de datos**        PostgreSQL
- **Estilos:**             Tailwind CSS
- **Iconografía:**         Imágenes SVG y PNG personalizadas

### Tipografía
- **Fuente principal:** `Inter`, sans-serif (por defecto en Tailwind CSS)

### Paleta de Colores
- **Fondo principal:** `#0f172a` (slate-900)
- **Fondo secciones:** `#1e293b` (slate-800)
- **Color primario:** `#22d3ee` (cyan-400) y `#22c55e` (green-500)
- **Texto principal:** `#fff` (blanco)
- **Texto secundario:** `#94a3b8` (slate-400)
- **Detalles/acento:** Gradientes azul, verde y púrpura

## Instalación y uso

1. Clona el repositorio
2. Instala dependencias: `npm install`
3. Inicia el proyecto: `npm run dev`
